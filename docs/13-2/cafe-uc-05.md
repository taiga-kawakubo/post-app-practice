# C-05: 注文一覧画面を表示する

## アクター
店員

## 事前条件
受け取り前の注文が1件以上ある。

## 基本フロー
1. 店員が注文一覧画面を開く。
2. システムが受け取り前の注文を、注文番号とともに一覧で表示する。
3. 店員がお客様から伝えられた注文番号の注文を選択する。
4. システムが選択された注文の商品と個数を表示する。
5. 店員が商品をお客様に渡す。

## 代替フロー
### 3a. 伝えられた注文番号が一覧にない場合
- システムは、該当する注文がない旨を表示する。

## 事後条件
対象の注文の商品と個数が画面に表示されている。

## 受け入れ条件
- [ ] 注文一覧画面に、受け取り前の注文が注文番号とともに表示される。
- [ ] 注文番号で注文を選ぶと、その注文の商品と個数が表示される。
- [ ] 該当する注文番号が存在しない場合、その旨が表示される。

#### UC-05: 注文を受け渡す

- **アクター**: 店員
- **事前条件**: 受け取り前の注文が1件以上ある
- **基本フロー**:

- **受け入れ条件**:
  - [ ] 注文一覧画面に、受け取り前の注文が注文番号とともに表示される
  - [ ] 注文番号で注文を選ぶと、その注文の商品と個数が表示される
  - [ ] 「受け渡し済みにする」を押すと、その注文が受け取り前の一覧から消える
