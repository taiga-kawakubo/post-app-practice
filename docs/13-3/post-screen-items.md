# 作成
## 画面項目一覧
| 項目名           | 種類               | 必須       | 内容             |
|:--------------- |:------------------|:---------- |:-------------- |
| 画面見出し | 表示 | - | 「投稿編集」 |
| タイトル | 入力(1行) | 必須 | 投稿のタイトル|
| カテゴリ　| 選択 | 必須 | 「お知らせ」「技術メモ」「雑記」から１つを選択|
| 本文 | 入力(複数) | 必須 |本文の内容を記述 |
| 更新 | ボタン | - | 押すと投稿が更新され投稿一覧画面に遷移する |
| キャンセル | リンク | 押すと保存せずに投稿一覧画面に遷移する |
